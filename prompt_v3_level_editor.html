02 — interface éditeur (editor.py)
## LAYOUT DE L'ÉCRAN ┌─────────────────────────────┬──────────┐ │ │ PALETTE │ │ CANVAS (grille de tiles) │ ──────── │ │ 960 × 500 px │ Tile │ │ scroll souris = pan │ courant │ │ │ ──────── │ │ │ Outils │ ├─────────────────────────────┤ ──────── │ │ STATUSBAR: coords | tile │ Ennemis │ └─────────────────────────────┴──────────┘ ## OUTILS (touches clavier) [1–7] sélectionne le tile/entité actif [B] brush (peinture maintien clic gauche) [F] fill bucket (flood fill récursif) [E] eraser → pose tile 0 (floor) [R] rectangle : clic+drag → remplit zone [L] ligne : clic+drag → trace ligne Bresenham [Ctrl+Z] undo (pile de 50 états) [Ctrl+Y] redo [Ctrl+S] save → levels/current.json [Ctrl+O] open → file dialog (pygame) [N] new level (demande W×H en tiles) [F5] test : lance main.py avec ce niveau [Tab] toggle : éditeur ↔ aperçu rendu final ## NAVIGATION CANVAS Molette souris → zoom (×0.5 à ×4) Clic molette + drag → pan (déplacement vue) Clic droit → efface tile (pose 0) Clic gauche → pose tile actif Shift+clic → pipette (prend le tile)
03 — placement d'entités avec popup
## ENTITÉS (couche séparée des tiles) Quand l'outil E (enemy) est actif et qu'on clique : → popup pygame (surface semi-transparente) : ┌─ PLACE ENEMY ────────────────┐ │ Weapon : [pistol ▾] │ │ Patrol : [static/loop/rand] │ │ Vision : [normal/wide/none] │ │ [OK] [Cancel] │ └──────────────────────────────┘ Résultat stocké en dict : { "type": "enemy", "gx": 12, "gy": 5, "weapon": "shotgun", "patrol": "loop", "vision": "wide" } Même principe pour W (weapon) : → choisir : pistol / shotgun / uzi / katana Les entités s'affichent sur le canvas comme des icônes colorées semi-transparentes par-dessus les tiles. Sélectionnable+supprimable avec Del.
04 — format de sauvegarde JSON
# levels/mon_niveau.json { "meta": { "name": "appartement_01", "width": 60, "height": 38, "tile_size": 16, "version": 2 }, "tiles": [ # liste plate, row-major [0,1,1,1, ...], # row 0 [1,0,0,0, ...], # row 1 ... ], "entities": [ {"type":"player_spawn","gx":2,"gy":2}, {"type":"enemy","gx":12,"gy":5, "weapon":"shotgun","patrol":"loop","vision":"wide"}, {"type":"weapon_pickup","gx":8,"gy":3,"weapon":"uzi"}, {"type":"exit_trigger","gx":58,"gy":36} ] } # map.py adapté pour lire ce format def load_level(path: str) -> Level: data = json.load(open(path)) level = Level(space, data["tiles"], data["meta"]) for ent in data["entities"]: level.spawn_entity(ent) return level

## CONTEXTE Tu es expert Python/Pygame. Ajoute un éditeur de niveau complet au jeu Neon Miami (v2 avec inertie, caméra rapprochée 480×270, tiles 16px). Crée un fichier editor.py autonome et adapte map.py pour charger les niveaux depuis JSON. ## FICHIERS À CRÉER / MODIFIER editor.py éditeur complet (nouveau) map.py adapter load_level(json_path) main.py ajouter arg --level chemin.json levels/ dossier de sauvegarde des niveaux ## TILE TYPES 0 = floor (sol vide) 1 = wall_thin (mur 16px fin, HP=2, destructible) 2 = wall_solid (mur porteur 32px, HP=4) 3 = floor_parquet (sol avec texture parquet) ## ENTITÉS (couche séparée) P = player_spawn (unique, requis) E = enemy (weapon, patrol, vision) W = weapon_pickup (pistol/shotgun/uzi/katana) X = exit_trigger (déclenche fin de niveau) ## INTERFACE ÉDITEUR (editor.py) Fenêtre 960×540. Deux panneaux : - Canvas gauche (860px) : grille de tiles scrollable - Palette droite (100px) : sélection tile/outil Navigation canvas : Molette → zoom ×0.5 à ×4 Clic molette + drag → pan Clic gauche → pose tile actif Clic droit → efface (pose floor) Shift+clic → pipette (copie tile sous curseur) Outils clavier : [1..7] sélectionne tile ou entité active [B] brush (peinture au clic maintenu) [F] fill (flood fill récursif, 4-connexe) [E] eraser (pose tile 0) [R] rectangle (drag → remplit rect) [L] ligne (algorithme Bresenham) [Ctrl+Z] undo (pile 50 états, deepcopy de tiles[]) [Ctrl+Y] redo [Ctrl+S] save → levels/current.json [Ctrl+O] ouvre un .json (listdir + sélection) [N] nouveau niveau : demande W H en tiles [F5] test in-game : subprocess.run main.py [Tab] aperçu rendu final (comme le jeu vrai) [G] toggle grille visible / cachée [Del] supprime entité sélectionnée Placement d'entité (E ou W actif) : → affiche popup pygame (surface 280×160) → champs : weapon, patrol (static/loop/rand), vision (normal/wide/none) → [OK] stocke dict dans entities[], [Cancel] annule Les entités sont dessinées comme icônes colorées semi-transparentes par-dessus les tiles. Clic sur entité existante → la sélectionne (Del). Status bar (bas d'écran, 30px) : "tile(12,5)=wall_thin | tool=brush | zoom=2x" ## FORMAT JSON DE SAUVEGARDE { "meta": { "name": string, "width": int, "height": int, "tile_size": 16, "version": 2 }, "tiles": [[int,...], ...], # row-major 2D list "entities": [ {"type":"player_spawn","gx":int,"gy":int}, {"type":"enemy","gx":int,"gy":int, "weapon":str,"patrol":str,"vision":str}, {"type":"weapon_pickup","gx":int,"gy":int, "weapon":str}, {"type":"exit_trigger","gx":int,"gy":int} ] } ## ADAPTATION MAP.PY Ajoute load_level(json_path, space) → Level. Level.__init__ accepte tiles 2D list + entities list. Garde la compatibilité avec la map hardcodée v2 (si aucun argument passé). ## ADAPTATION MAIN.PY import argparse parser.add_argument("--level", default=None) Si --level fourni → load_level(path) Sinon → niveau par défaut hardcodé. Exemple de lancement : python editor.py # ouvre l'éditeur python main.py # niveau par défaut python main.py --level levels/mon_niveau.json ## CONTRAINTES - Pas de dépendances hors pygame + pymunk + stdlib - Undo via deepcopy(tiles) avant chaque modification - Flood fill iteratif (pile Python, pas récursif) pour éviter RecursionError sur grandes maps - editor.py doit tourner indépendamment du jeu - Sauvegarde auto (Ctrl+S) avant F5 - Génère requirements.txt et README bref avec les raccourcis claviers documentés Génère le code complet fichier par fichier.
