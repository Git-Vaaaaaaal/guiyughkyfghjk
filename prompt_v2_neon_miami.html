01 — mouvement avec inertie
## MOUVEMENT JOUEUR — inertie réaliste Le joueur ne s'arrête pas immédiatement. Implémente une inertie par interpolation de vélocité : # Dans player.py — update de la vitesse ACCEL = 1400 # px/s² — accélération au sol FRICTION = 8.0 # facteur lerp quand aucune touche MAX_SPD = 190 # px/s vitesse max Si touche pressée → accélère vers la direction vx += dir_x * ACCEL * dt vy += dir_y * ACCEL * dt clamp(|v| ≤ MAX_SPD) Si aucune touche → freinage doux (lerp vers 0) vx = lerp(vx, 0, FRICTION * dt) vy = lerp(vy, 0, FRICTION * dt) Résultat : ~150–200ms de glisse à l'arrêt. Le dash annule l'inertie et applique une impulsion directe de 480 px/s.
02 — caméra rapprochée avec lag doux
## CAMÉRA — zoom tactique serré Zone visible : 480 × 270 px (moitié de 960×540) → rendue puis upscalée ×2 sur l'écran final. Ou : viewport interne = 540 × 304 (ratio 16:9, ×1.77). # La caméra suit le joueur avec lag : CAM_SMOOTH = 6.0 # lerp factor target_cx = player.x - VIEW_W/2 target_cy = player.y - VIEW_H/2 cam_x = lerp(cam_x, target_cx, CAM_SMOOTH * dt) cam_y = lerp(cam_y, target_cy, CAM_SMOOTH * dt) # Option avancée : décaler vers la visée look_x = (mouse_x - VIEW_W/2) * 0.25 look_y = (mouse_y - VIEW_H/2) * 0.25 cam_x += look_x # anticipe la direction du tir Clamp : ne pas sortir des bords du niveau.
03 — map style appartement (plan de maison)
## LEVEL DESIGN — appartement cyberpunk Tile size = 16px (au lieu de 32px) Épaisseur des murs = 1 tile (16px) sauf murs porteurs = 2 tiles. Taille du niveau : environ 60 × 38 tiles (960 × 608 px en mémoire). Pièces obligatoires (plan d'appartement) : - Entrée / couloir central (2–3 tiles large) - Salon (grande pièce ouverte) - Cuisine (L-shape avec îlot) - 2 chambres (petites, portes étroites) - Salle de bain (1×2 tiles, cul-de-sac) - Bureau / salle serveur (ambiance cyberpunk) - Terrasse / balcon (ouverture sur extérieur) Portes = gap d'1 tile dans les murs (sans sprite). Couloirs = exactement 2–3 tiles de large pour forcer les confrontations à courte portée. ## RENDU DES MURS FINS Mur = rect de 16px de large, couleur dark. Bord supérieur/gauche : ligne de 1px CYAN_DIM (effet de lumière néon sur l'arête du mur). Intérieur : légère texture de brique 4×4px. Sol : parquet bois foncé (lignes horizontales tous les 8px en FLOOR_LINE_COLOR). ## DESTRUCTION WALL_MAX_HP = 2 (murs fins → cassent en 2 tirs) Murs porteurs (2 tiles) : HP = 4, indestructibles visuellement différents (couleur béton #3a3040).
